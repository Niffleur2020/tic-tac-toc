# Tic-Tac-Toe - Morpion en C

## Présentation

Projet personnel réalisé en langage C dans le cadre de mon apprentissage de la programmation.

Jeu de morpion où le joueur affronte l'ordinateur sur un plateau de 3x3 cases.

## Fonctionnalités

- Plateau de jeu 3x3.
- Joueur : X.
- Ordinateur : O.
- Vérification des victoires.
- Détection des matchs nuls.
- Vérification des cases occupées.
- Vérification des entrées du joueur.

## Technologies

- Langage C
- GCC
- Makefile
- Git
